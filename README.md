💡 Sobre o projeto

Esse projeto foi desenvolvido para praticar fundamentos de HTML semântico e CSS, com foco em fidelidade visual ao layout original, organização de código (Flexbox, box model) e responsividade para dispositivos móveis.

⚙️ Funcionalidades
🖥️ Layout fiel à página inicial da Uber (header, hero, seções institucionais, área de apps e footer)
📱 Design responsivo, adaptado para desktop e mobile
🎨 Efeitos de hover em botões e imagens
🧩 Seções organizadas: cadastro de motorista, plataforma para empresas, segurança, sobre a empresa, download do app e cadastro
🛠️ Tecnologias utilizadas
HTML5 — estruturação semântica da página
CSS3 — estilização, Flexbox, media queries e efeitos de transição
Font Awesome — ícones utilizados ao longo da página
🗂️ Estrutura do projeto
Clone-pagina-home-Uber/
├── index.html      # Estrutura principal da página
├── styles.css       # Estilização completa e responsividade
└── images/          # Imagens utilizadas no projeto (logo, banners, ícones, etc.)
🧠 Conceitos praticados
HTML semântico e organização de seções
Flexbox para alinhamento e distribuição de elementos
Boas práticas de nomenclatura de classes CSS
Responsividade com media queries (@media)
Organização de assets em pastas (imagens separadas do código)
Boas práticas de commits (ex: renomeação de arquivos, refatoração de CSS para melhorar responsividade)
